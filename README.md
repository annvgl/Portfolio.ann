# Portfolio.ann

A modern, responsive portfolio website showcasing projects, skills, and experience.

## 🌟 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Interactive Navigation**: Smooth scrolling and active section highlighting
- **Sections**:
  - Hero section with introduction
  - About section with personal description
  - Projects showcase with technology tags
  - Skills overview organized by categories
  - Contact section with links

## 🚀 Viewing the Portfolio

### Option 1: Local Viewing
Simply open the `index.html` file in your web browser:
```bash
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

### Option 2: GitHub Pages
This portfolio can be deployed to GitHub Pages:
1. Go to repository Settings
2. Navigate to Pages section
3. Select source branch (main/master)
4. The site will be available at `https://annvgl.github.io/Portfolio.ann/`

### Option 3: Local Server
For a better development experience, use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server

# Then visit http://localhost:8000
```

## 🎨 Customization

To customize the portfolio for your needs:

1. **Personal Information**: Edit the text content in `index.html`
2. **Projects**: Update the project cards in the Projects section
3. **Skills**: Modify the skill categories and items
4. **Contact Links**: Update the email and social media links
5. **Colors**: Change CSS variables in `styles.css` (`:root` section)
6. **Styling**: Adjust styles in `styles.css`

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS Variables and Flexbox/Grid)
- Vanilla JavaScript
- No external dependencies required!
